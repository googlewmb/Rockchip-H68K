# Rockchip H68K OpenWrt 固件

主要面向 **H68K（Rockchip RK3568）** 编译，同时提供 OpenWrt、LEDE、iStoreOS 等不同版本固件。

## 📌 项目说明

- 主要编译设备：**H68K（RK3568）**
- 默认开启无线 AP
- 默认使用官方默认管理 IP
- 默认使用对应系统的官方默认密码（如系统默认无密码，则无密码）
- 支持自定义编译插件
- 所有固件均通过 GitHub Actions 自动编译

---

## 🧩 固件版本

### OpenWrt

- `openwrt-main`
- `test-openwrt`

特点：

- OpenWrt 主线源码
- 尽量保持原汁原味
- 纯净、少修改
- 默认开启无线 AP
- 包含全锥 NAT 补丁
- 跟随 OpenWrt 主线更新
- 全锥 NAT 补丁可能存在稳定性问题，请自行选择是否使用

---

### LEDE

默认跟随 LEDE 主线编译。

说明：

- 旧版 LEDE 曾出现网口识别问题
- 新版理论上已经改善
- 暂未发现新的明确问题
- 如实际使用中出现网口异常，请提供系统日志进行反馈

---

### iStoreOS 24.10

提供 iStoreOS 24.10 固件及完整依赖环境。

特点：

- H68K / RK3568 默认配置
- 完整 iStoreOS 相关依赖
- 完整 Daed / Daede 相关依赖
- 默认开启无线 AP
- 支持自定义插件编译

---

### iStoreOS 25.12

推荐使用版本。

默认配置：

- H68K / RK3568
- 四个网口正常工作
- 默认无登录密码
- 无线默认无密码
- 最大连接数：`655550`
- 默认开启无线 AP
- 支持自定义插件

**推荐 H68K 用户直接使用。**
